# Механики баланса для «МОЛОКО» — план реализации

## Как это будет работать (дизайн)

**Жетоны (гибрид):** каждый получает 1 жетон на старте матча; в каждом завершившемся раунде все, кто не угадал слово, получают ещё по 1. Максимум 2 жетона на руках (анти-затяжник). Обнуляются только при реванше.

**Усиления:**
- 🤫 **Проверка буквы** — тратишь жетон, ход НЕ тратишь, доступна в любой момент (даже не в твой ход). Выбираешь букву на мини-грид А-Я, ответ видишь только ты: «К — есть» / «Д — нет». Появляется в твоей личной панели подсказок.
- 📍 **Открыть букву** (за жетон + свой ход) — выбираешь позицию 1–5, буква раскрывается **публично** для всех (бейдж над полем «Позиция 3: К»).
- 🔄 **Сменить слово** (жетон + ход) — новое слово для всех; история попыток остаётся видимой, но помечается «старое слово» (данные от прежнего слова — их можно учитывать, это часть стратегии); личные подсказки у всех сгорают.
- 🧊 **Заморозка** (жетон + ход) — следующий по очереди пропускает ход («Молоко скисло»).
- 👂 **Шёпот Зорьки** (жетон + ход) — приватно 3 слова из словаря, совместимых со всеми открытыми данными.

Слово никогда не покидает сервер: приватные подсказки рассылаются точечно одному сокету, в общий снапшот не попадают.

**Порядок ходов «Яйцо-Курица»:**
1. Раунды 1, 4, 7… начинаются с розыгрыша: каждый тайно выбирает 🥚 или 🐔 (голоса скрыты до конца).
2. Меньшинство выбирает свою позицию в очереди первым (любую из свободных).
3. Остальные играют в **Сыр-Молоко-Кувшин** (цикл: сыр затыкает кувшин, кувшин наливает молоко, молоко створаживается в сыр; ничья — переброс; выбывшие выстраиваются с конца) — победители по очереди выбирают позиции.
4. Если все выбрали одинаково или 50/50 — весь стол играет в СМК.
5. Итоговый порядок живёт **3 раунда, стартующий сдвигается на позицию каждый раунд** — очередь видна заранее (полоска порядка с аватарками и стрелкой).

**Баланс (п.3):** сильнейшая позиция — последняя в круге (крадёт победу на готовой инфе), слабейшая — первая. Компенсация: сдвиг старта каждый раунд + жетоны неугадавшим + заморозка как защита от «украсть у соседа». Всё это появится в README.

**Словарь:** сильно расширим. Скрипт скачает открытый список русских существительных (Harrix/Russian-Nouns, ~51к слов), отфильтрует 5-буквенные → получится несколько тысяч слов для **проверки** попыток; список **загадываемых** останется курированным (расширю вручную до ~700 частых слов), чтобы не загадывать дичь. Если сеть не даст — fallback на ручное расширение.

## Изменения в коде

1. **`scripts/build-dicts.mjs`** — скачивание + фильтрация словаря → `src/game/words-extra.json`; `words.js` → ANSWERS (курированные) + GUESSES (все); `logic.js` — валидация по всем, загадывание из ANSWERS.
2. **`server/index.js`** — новые фазы (draw/smk/pickpos), розыгрыш порядка, ротация старта по блокам, жетоны, все 5 усилений, приватная рассылка, заморозка-скип, пометка старых рядов при смене слова.
3. **`src/game/lines.js`** — реплики Зорьки: розыгрыш, СМК, заморозка, шёпот, смена слова, жетоны.
4. **Клиент**: `DrawOverlay` (яйцо/курица), `SmkOverlay` (сыр/молоко/кувшин), `PickPosOverlay` (выбор позиции), `PowerMenu` + грид букв, личная панель подсказок, полоска порядка ходов, бейджи публичных открытых букв, приглушённые «старые» ряды, счётчик жетонов на табло.
5. **`useParty.js`** — новые действия (drawPick, smkPick, pickPos, usePower, checkLetter) и приём приватных сообщений.
6. **`scripts/test-mechanics.mjs`** — автотесты: розыгрыш (меньшинство/СМК), ротация старта, жетоны и лимит, каждое усиление, приватность (шёпот и проверка не утекают в общий state).
7. **README/SETUP** — обновить описание режимов.

## Порядок работы
Словарь → сервер → тесты сервера → клиент → браузер-проверка (лобби-розыгрыш, усиления, заморозка) → сборка.
