# MilkWordle — запуск игры в Discord (Activity)

Игра работает в двух режимах:
- **Соло** — открываешь `http://localhost:5173` в браузере и играешь одна/один.
- **Комната с друзьями** — Activity внутри Discord: общее слово, синхронные тики, очки до победы.

Ниже — как поднять комнату в Discord. Займет ~15 минут один раз.

---

## Шаг 0. Что уже работает без Discord

```bash
npm install        # один раз
npm run dev        # vite (5173) + игровой сервер (3001)
```

Открыть в браузере `http://localhost:5173` — соло-режим.
Открыть `http://localhost:5173/?party=1` — отладка комнаты в браузере
(каждая вкладка = отдельный игрок, можно гонять матч с самим собой).

---

## Шаг 1. Создай приложение в Discord

1. Зайди на https://discord.com/developers/applications -> **New Application**.
2. Назови (например, «MilkWordle») и сохрани **Application ID**.
3. Слева **Activities** (или «Embedded App» — название пункта меняется) ->
   включи **Enable Activities**.
4. Там же найди **URL Mappings** и добавь маппинг:
   - префикс/путь: `activities`
   - URL: адрес, где игра доступна по **HTTPS** (см. шаг 3 — ngrok).
5. Слева **OAuth2**:
   - скопируй **Client ID**;
   - нажми **Reset Secret** и скопируй **Client Secret**;
   - в **Redirects** добавь тот же HTTPS-адрес (например `https://xxxx.ngrok-free.app`).

## Шаг 2. Пропиши ключи

```bash
copy .env.example .env
```

В `.env`:

```
VITE_CLIENT_ID=<Application/Client ID>
CLIENT_SECRET=<Client Secret>
```

Secret никому не показывай — он работает только на сервере.

## Шаг 3. HTTPS через ngrok

Discord грузит Activity только по HTTPS, поэтому localhost заворачиваем в туннель.

1. Скачай ngrok: https://ngrok.com/download (нужен бесплатный аккаунт + authtoken).
2. Запусти игру и туннель в двух окнах:

```bash
npm run dev          # окно 1: игра
ngrok http 5173      # окно 2: туннель
```

3. ngrok выдаст адрес вида `https://a1b2-xx-xx.ngrok-free.app` —
   **впиши его** в URL Mapping и OAuth2 Redirect из шага 1.

> Адрес ngrok меняется при каждом перезапуске бесплатного тарифа —
> тогда обнови его в Developer Portal.

## Шаг 4. Добавь игру на свой сервер

1. В Developer Portal: **OAuth2 -> URL Generator** (или «Installation»).
2. Отметь скоупы: `applications.commands` и `applications.activities`
   (если портал требует — добавь еще `bot`).
3. Открой сгенерированный URL, выбери свой сервер, подтверди.

## Шаг 5. Запуск в голосовом канале

1. Зайди с друзьями в голосовой канал на этом сервере.
2. Внизу слева нажми иконку **ракеты/приложений** (Activities launcher).
3. Найди «MilkWordle» и жми **Launch**.
4. Все, кто в канале, попадут в комнату: хост нажимает «Начать матч» — погнали.

Хост задает лимит очков (32/48/64/96). Кто первым набрал лимит — чемпион хлева, дальше кнопка «Реванш».

## Продакшен (без ngrok)

На любом хостинге (VPS, Render, Railway) с Node 18+:

```bash
npm run build   # собирает dist/
npm start       # сервер отдает игру + ws + api на одном порту (PORT, по умолчанию 3001)
```

Один процесс на все: статику, WebSocket `/ws` и OAuth-обмен `/api/token`.
Тот же HTTPS-адрес вписывается в URL Mapping и OAuth2 Redirect.

## Ограничения и правила

- Непроверенные Activities запускаются только на серверах **до 25 участников** —
  для игры с друзьями этого достаточно. Публичная публикация требует верификации Discord.

## Если что-то не работает

| Симптом | Причина / решение |
|---|---|
| В Activity пустой белый экран | URL Mapping не совпадает с ngrok-адресом, или ngrok перезапустился и адрес сменился |
| Висит «Подключаемся к Discord…» | Не заполнен `VITE_CLIENT_ID` или не запущен `npm run dev` |
| Ошибка авторизации после кнопки Authorize | Неверный `CLIENT_SECRET` или redirect в Dev Portal не совпадает с адресом в адресной строке |
| `EADDRINUSE :3001` | Уже висит старый сервер: закрой его (`taskkill /F /IM node.exe` — убьет все node, аккуратно) или смени `PORT` |
| Друзья не видят игру в лаунчере | Приложение не добавлено на сервер (шаг 4) или скоупы не те |
