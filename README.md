# МОЛОКО 🥛 — wordly по-коровьи

Угадайка слов в стиле Wordle с характером: маскот Зорька (флиртующая корова),
коровья раскраска, процедурный звук на WebAudio и дерзкие комментарии к каждой попытке.
Два режима: соло против Зорьки и соревновательная комната с друзьями (внутри Discord Activity или прямо в браузере).

## Режимы

**Соло** (`SoloGame`):
- **Обычный (бесконечный)** и **📅 Слово дня** (одно общее слово в сутки для всех по дате, языку и длине слова);
- поддержка **русского (🇷🇺)** и **английского (🇬🇧)** языков, длина слова: **5, 6 или 7 букв**;
- 6 попыток: коричневая плитка — буква на месте, желтая — есть в слове, серая — мимо;
- копирование результата с эмодзи-сеткой `🟫🟨⬜` в буфер обмена и статистика в `localStorage`;
- прямое переключение **Соло ↔ Комната** прямо из шапки игры.

**Комната** (Discord Activity или кнопка `🐄 Комната` / `?party=1`):
- список открытых комнат + создание **скрытых комнат** (вход по 4-значному коду);
- возможность добавить **ИИ-ботов** (`🤖 Бычок Борька`, `🤖 Коза Дереза` и др.), которые сами анализируют буквы и соревнуются за очки;
- настраиваемый хостом темп тика (**15с / 30с / 45с**), длина слова (**5 / 6 / 7**), язык (**RU / EN**), режим видимости (**🔒 Закрытый / 🔓 Открытый**) и лимит очков (**32 / 48 / 64 / 96**);
- **синхронные тики**: все игроки одновременно угадывают одно слово на своих досках (раунд длится до 6 тиков). Кто угадал раньше — срывает куш: `32 / 16 / 8 / 4 / 2 / 1` очко (при одновременном угадывании очки тика делятся поровну);
- в конце каждого раунда раскрываются все слова, которые наливали соперники;
- в конце матча на пьедестале выдаются **титулы и медали** (*🎯 Снайпер дойки*, *🐀 Крыса хлева*, *🕵️ Главный шпион*, *🕶️ Вслепую*, *🪣 Водовоз*).

**Талоны и способности.** Каждый получает 2 талона на старте матча и по +1 талону за раунд без победы или пропуск тика (максимум 4 в кошельке):

| Способность | Цена | Что делает |
|---|---|---|
| 🥛 Первые сливки | 1 талон (ход не тратится) | Приватно проверяет, есть ли выбранная буква в слове |
| 🎯 Снайперский подойник | 2 талона (ход не тратится) | Приватно проверяет букву на конкретной позиции |
| 🕵️ Прошлые надои | 2 талона (ход не тратится) | Подсматривает написанные слова выбранного соперника (порядок перемешан) |
| 👀 Сексуальная разведка | 1 талон + попытка | Кладет 2 случайных слова из словаря на твою доску |
| 🐄 Белковый перехват | 2 талона + попытка | Подменяет слово выбранного противника в текущем тике на случайное |
| 🕵️ Деревенская кража | 3 талона + попытка | В конце тика меняет общее слово раунда (старые ряды помечаются) |

**🎲 События Зорьки** (включаются в лобби, срабатывают со 2-го раунда):
- 🌟 **Золотой надой** — очки за угадывание слова в этом раунде удваиваются (`×2`);
- 🥛 **Щедрый хлев** — все игроки получают `+2` талона на старте раунда;
- 🔓 **Парное молоко** — первая буква слова сразу раскрыта всем в приватных знаниях.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 — соло и комната в браузере
```

Discord-комната: см. [SETUP.md](SETUP.md) (Developer Portal + ngrok, один раз ~15 минут).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | vite + игровой сервер вместе (для разработки и ngrok) |
| `npm run dev:web` | только vite (соло в браузере) |
| `npm run build` | продакшен-сборка в `dist/` |
| `npm start` | сервер: раздача `dist/` + WebSocket + OAuth (порт `PORT`, по умолчанию 3001) |
| `npm run test:server` | автотест сервера (тики, очки, способности, 6 букв, EN) |
| `npm run check:words` | проверка базового словаря |

## Как устроено

```
src/
  game/words.js        — базовый русский словарь на 5 букв
  game/words-ru67.js   — русские словари на 6 и 7 букв
  game/words-en.js     — английский словарь на 5 букв
  game/words-en67.js   — английские словари на 6 и 7 букв
  game/logic.js        — валидация, оценка попыток, слово дня, подбор кандидатов для ботов
  game/lines.js        — реплики Зорьки
  game/sfx.js          — синтезатор звуков на WebAudio
  hooks/useSoloGame.js — состояние соло-игры (обычный режим и Слово дня)
  discord/discord.js   — Discord SDK: авторизация, переключение режимов
  discord/useParty.js  — клиент комнаты (WebSocket)
  components/          — Board, Keyboard, Cow, Splash, SoloGame, PartyGame, Toast
server/index.js        — HTTP: OAuth-обмен + статика; WS: комнаты, тики, способности, боты, события
```

## Контент

Зорька флиртует и отпускает намеки — это сознательный потолок: Discord Activity доступна без возрастного рейтинга, откровенный контент там запрещен.
