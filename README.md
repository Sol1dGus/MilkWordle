# МОЛОКО 🥛 — wordly по-коровьи

Угадайка слов в стиле Wordle с характером: маскот Зорька (флиртующая корова),
коровья раскраска, пошлые (но пристойные) комментарии к каждой попытке.
Два режима: соло против Зорьки и комната с друзьями внутри Discord.

## Режимы

**Соло** — классика: 6 попыток, слово из 5 русских букв. Коричневая плитка —
буква на месте, желтая — есть в слове, серая — мимо. Ввод с клавиатуры
(раскладка не важна) или кликами. Статистика хранится в браузере.

**Комната** (Discord Activity или `?party=1`) — соревновательный режим:

- перед матчем и каждые 3 раунда — **розыгрыш порядка**: все тайно выбирают
  🥚 или 🐔; меньшинство первым разбирает места в очереди, остальные играют в
  **Сыр-Молоко-Кувшин** (сыр затыкает кувшин, кувшин наливает молоко,
  молоко створаживается в сыр); ничья или «все как один» — СМК для всего стола;
- порядок ходов виден заранее (полоска «места/старты») — на нем строится стратегия;
- одно слово на всех, ходы строго по кругу, результат попытки видит вся комната;
  рядов не шесть, а сколько нужно — пока кто-то не угадает;
- угадал — очко, играем до N очков (хост выбирает 1/3/5/10); после матча —
  пьедестал и реванш;
- стартующий каждый раунд сдвигается на позицию: все побывают и «открывашкой»,
  и на жирной последней позиции.

**Жетоны и усиления.** Каждый получает 1 жетон на старте матча, и по жетону
достается всем неугадавшим в раунде (максимум 2 на руках):

| Усиление | Цена | Что делает |
|---|---|---|
| 🤫 Проверить букву | жетон, ход не тратится | проверяешь букву — ответ видишь только ты |
| 📍 Открыть букву | жетон + ход | публично раскрывает букву на выбранной позиции |
| 🔄 Сменить слово | жетон + ход | новое слово всем; старые ряды помечаются, личные подсказки сгорают |
| 🧊 Заморозка | жетон + ход | следующий по очереди пропускает ход |
| 👂 Шепот Зорьки | жетон + ход | приватно 3 слова из словаря, совместимых с открытым |

**Почему это сбалансировано:** сильнейшая позиция в круге — последняя (крадет
победу на собранной информации), слабейшая — первая (работает вслепую).
Ротация стартующего выравнивает шансы за 3 раунда, жетоны неугадавшим тянут
отстающих вверх, а заморозка — инструмент против соседа, который собирается
украсть твою победу. Летящие реакции 🐮🥛👏😏🔥 и язвительные комментарии
Зорьки прилагаются.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 — соло, ?party=1 — комната в браузере
```

Discord-комната: см. [SETUP.md](SETUP.md) (Developer Portal + ngrok, один раз ~15 минут).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | vite + игровой сервер вместе (для разработки и ngrok) |
| `npm run dev:web` | только vite (соло в браузере) |
| `npm run build` | продакшен-сборка в `dist/` |
| `npm start` | сервер: раздача `dist/` + WebSocket + OAuth (порт `PORT`, по умолчанию 3001) |
| `npm run test:server` | автотест матча на 4 игроков (поднимает свой сервер на :3099) |
| `npm run check:words` | проверка словаря (длина 5, без дублей) |

## Как устроено

```
src/
  game/words.js        — словарь: 414 русских существительных из 5 букв
  game/logic.js        — оценка попытки (честно про повторные буквы), клавиатурные метки
  game/lines.js        — реплики Зорьки
  hooks/useSoloGame.js — состояние соло-игры
  discord/discord.js   — Discord SDK: авторизация, распознавание режима
  discord/useParty.js  — клиент комнаты (WebSocket)
  components/          — Board, Keyboard, Cow, Splash, SoloGame, PartyGame, Toast
server/index.js         — HTTP: OAuth-обмен + статика; WS: комната (источник правды)
```

Партия авторитетна на сервере: слово не покидает сервер до конца раунда,
все ходы и очки считает он, клиент только рисует присылаемый снимок состояния.
Отладочный режим сервера: `DEBUG_WORD=масло npm run dev` — все раунды с одним словом.

## Контент

Зорька флиртует и отпускает намеки — это сознательный потолок: Discord
Activity доступна без возрастного рейтинга, откровенный контент там запрещен.
